# Cahuachi

Sitio web editorial para dar a conocer la ciudadela ceremonial de Cahuachi y la cultura Nasca.

## Uso local

Abre `index.html` directamente en el navegador. No necesita dependencias ni proceso de compilación.

## Publicar en GitHub Pages

```bash
git init
git add .
git commit -m "Crear sitio de Cahuachi"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/cahuachi.git
git push -u origin main
```

Después, en GitHub: `Settings > Pages > Deploy from a branch > main / root`.

El sitio usa los recursos visuales incluidos en esta carpeta y funciona como una página estática.
